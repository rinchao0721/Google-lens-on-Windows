lenswin —— Windows 托盘以图搜图工具

使用
  1. 运行 lenswin.exe，托盘出现图标。
  2. 默认快捷键：Win+Shift+A 圈选搜索，Win+Shift+C 截屏到剪贴板。
     快捷键被其它程序占用时，可在托盘菜单「设置…」里修改。
  3. 首次上传前会提示图片将上传到哪个图床，确认后才会上传。

便携版
  - 本目录里的 portable 文件表示便携模式：配置和日志保存在 data 文件夹，
    不写入 %APPDATA%。请保留该文件。
  - 目录不可写（例如放进 Program Files）时，会改用 %APPDATA% 并在托盘提示。
  - 升级：覆盖解压即可，data 文件夹会保留。
  - 卸载：先在托盘菜单关闭「开机自启」，再删除整个文件夹。
